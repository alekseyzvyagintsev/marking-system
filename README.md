# marking-system

Система управления маркировкой товаров (шин) в рамках регуляторной системы «Честный ЗНАК».

## Описание

Проект описывает процессы работы с кодами маркировки: получение, хранение, маркировка и отгрузка товаров с соблюдением требований регулятора.

В рамках анализа выявлены критические противоречия между требованиями регулятора, физическими условиями склада и текущими бизнес-процессами. Подробнее см. [Выявленные противоречия и способы их решения](docs/contradictions.md).

## Структура

- **docs/** — требования регулятора, противоречия и предлагаемые решения
- **matrix.md** — матрица трассируемости требований
- **assets/diagrams/** — диаграммы процессов
