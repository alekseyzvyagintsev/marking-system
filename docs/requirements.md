# Требования регулятора и бизнес-требования

## Регуляторные требования
- Обязательное сканирование кодов при отгрузке
- Запрет на хранение полных кодов более 60 дней
- Вывод из оборота при фактической отгрузке
- Привязка кода к физическому товару
- Соблюдение правил перемаркировки

## Бизнес-требования
- Сохранение скорости обработки заказов
- Минимизация ручного труда
- Обеспечение точности данных
- Поддержка различных сценариев работы
- Интеграция с существующими системами
